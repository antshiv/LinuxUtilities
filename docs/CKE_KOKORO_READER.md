# CKE Kokoro reader

The maintained guide is [the published HTML page](https://antshiv.github.io/LinuxUtilities/cke-kokoro-reader.html), authored in [docs/_pages/cke-kokoro-reader.html](_pages/cke-kokoro-reader.html).

This optional local adapter does not provide P3-to-laptop transport. Protocol tests use fake CKE components and do not certify synthesis or headset playback.
